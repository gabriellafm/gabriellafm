## O que já entreguei

- 🏆 Liderei a migração de 200 repositórios do GitHub para GitLab
  Self-Managed — preservando histórico completo, integrações de CI/CD
  e sem impacto para usuários finais
- 💰 Redução de ~R$150 mil/ano em custos de licenciamento
- 🔒 Arquitetura de alta disponibilidade em cloud privada com controle
  de acesso centralizado e políticas de backup
- ⚙️ Implementação de pipelines CI/CD integrados ao SonarQube com
  portões de qualidade
- 🛡️ Administração de IAM na AWS 
- 📋 Administração técnica do Jira para times de toda estrutura de TI, Digital & Inovação
